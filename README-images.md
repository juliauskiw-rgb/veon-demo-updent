# Изображения демо: откуда взято каждое

19.11.2026 была одна попытка скачать с сайта клиента (`curl -m 20 https://updent.com.ua/images/logo.png`): ответа нет (HTTP 000, сервер ограничил частоту запросов). Больше запросов не было. Все изображения вырезаны из скриншотов аудита `audit/screens/` (материалы самого клиента) скриптом на Python PIL, без фильтров и ретуши. В браузер они попадают через `astro:assets` (`<Picture>`: AVIF и WebP, `srcset`, `width`/`height`; размеры не больше исходных).

**Ограничения качества.** Фото на сайте клиента отданы в небольшом размере, скриншоты сняты в 1440 px (десктоп) и 390 px при 2x (мобильный), поэтому самое большое фото 1277 px. Портреты врачей на скриншотах есть только 218×298 px (и только четыре из шести), при показе они размываются, поэтому после ревью 19.11.2026 переключение портретов убрано: в блоке команды одно групповое фото и список врачей. Когда клиент даст исходники, файлы заменяются под теми же именами, код менять не нужно.
